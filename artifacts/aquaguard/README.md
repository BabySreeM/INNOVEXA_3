## 🏃 Quick Start (Dashboard Component)

```bash
# Install dependencies
pnpm install

# Start local dev server
pnpm dev

# Run WhatsApp Telemetry Bot Server
pnpm wa-bot
```

Without Firebase environment variables, click **Run in Demo Mode** on the dashboard entry screen.
